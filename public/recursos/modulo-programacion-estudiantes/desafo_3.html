Retroalimentación

Cada vez que se ejecuta el siguiente bloque se suma el valor uno al valor que posee almacenado la variable llamada voto

 Debido a que la iteración repetir hace que dicho bloque se ejecute tres veces, se puede concluir que se sumará tres veces el valor uno.

Teniendo en cuenta que este bloque inicializa la variable con el valor dos, se deduce que se sumará tres veces el valor uno al valor dos: 2+1+1+1.

En  consecuencia, el valor que almacenará la variable en el momento en que se ejecute el siguiente bloque será cinco.

Retroalimentación

Cada vez que se ejecuta el siguiente bloque se almacena el valor dos en la variable llamada voto.

Cada vez que se ejecuta el siguiente bloque se suma el valor uno al valor que posee almacenado la variable llamada voto.

 Se deduce que al finalizar cada iteración, la variable almacena el valor numérico tres.

En  consecuencia, el valor que almacenará la variable voto en el momento en que se ejecute el siguiente bloque será tres. 

Se deduce que el valor que se mostrará en la pantalla será tres.

Al inicio dirá el valor numérico siete. A continuación, en cada iteración, aumentará en uno el valor a decir.

Siempre dirá el valor numérico uno.

Retroalimentación

Este bloque inicializa la variable con el valor cinco..

En cada iteración se suma uno al valor que ya poseía almacenado la variable. Por lo tanto, luego de ejecutar estos bloques, el valor de la variable será siete.

Debido a que el valor de la variable llamada puntos es siete, esta expresión lógica resulta falsa y por lo tanto, no se ejecutarán las instrucciones de la sentencia condicional.

Debido a lo anterior,  cuando se ejecuta este bloque  el valor de la variable es siete, por lo que el gato dirá dicho valor numérico.
