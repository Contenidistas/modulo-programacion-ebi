Introducción a la programación

Introducción

Una computadora es un dispositivo capaz de realizar múltiples tareas a partir de una inmensa cantidad de cálculos y operaciones. Para realizar esas tareas se requiere la interacción de tres elementos, el hardware, el software y el usuario. Todo software es un programa o un conjunto de programas, existen muchos tipos de software.

La programación es una fase en la construcción de software, se entiende por programar a la acción de escribir sentencias o instrucciones de forma tal que la computadora las pueda interpretar.
