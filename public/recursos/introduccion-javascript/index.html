Introducción a Javascrip

¿Qué es Javascript?

Javascrip es un lenguaje de programación que nace en 1995 con la finalidad de agregar programación a páginas web, en particular a Netscape Navigator. Desde ese entonces no ha parado de crecer como lenguaje de programación orientado a objetos dentro de entornos web, esto permite crear código dentro de una estructura de página web html, de esta forma podremos ejecutar el código con el navegador que tengamos instalado.

Son perjuicio de esto, existen muchos detractores de Javascript, su principal crítica radica en la gran flexibilidad y simpleza. En el campo educativo esto es una ventaja.

Su nombre guarda similitud al de un lenguaje muy conocido como es Java, pero no tienen relación alguna.

Lectura facilitada

Es un lenguaje de programación orientado a objetos.

Sus programas son ejecutados por un navegador web.
