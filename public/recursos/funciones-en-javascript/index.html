Inicio

Introducción

En el recurso introducción a  JavaScript se vieron los conceptos fundamentales de programación implementados en este lenguaje de programación (JavaScript). Es bueno recordar que se utilizó Netbeans como entorno de desarrollo integrado (IDE),  esto fue solo una elección entre muchas posibles, se puede programar en JavaScript en otros entornos de desarrollo, al igual que se puede programar en otros lenguajes de programación.

Lectura facilitada

En el recurso de introducción a JavaScript, aprendimos los conceptos básicos de programación implementados en este lenguaje. Usamos Netbeans como un programa para escribir código, pero hay muchos otros programas que se pueden usar. Al igual que se pueden usar diferentes programas para escribir en otros lenguajes de programación, JavaScript también se puede escribir en otros lugares además de Netbeans.

Descripción

Este recurso educativo abierto está diseñado para facilitar a los docentes la planificación competencial para el trabajo con funciones en JavaScript, ofreciendo una guía detallada que abarca desde conceptos básicos hasta la aplicación en proyectos complejos. A través de una secuencia pedagógica progresiva.

Además, se presentan a modo de ejemplo metas de aprendizaje asociadas a los criterios de logro y competencias específicas respectivas con actividades de ejemplo en niveles progresivos: desde el conocimiento y comprensión de qué son las funciones y cómo se utilizan, hasta la creación y evaluación de soluciones de programación innovadoras que integran funciones avanzadas.
