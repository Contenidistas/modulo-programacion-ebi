Valor de una variable

Una variable solamente puede guardar un dato a la vez. 

El valor de una variable es el dato que está almacenado. Dicho valor podrá modificarse durante la ejecución del programa las veces que sea necesario.
Una vez que se cambia un dato por otro, el dato que fue cambiado se pierde y no es recuperable. Si necesito conservar el dato previo deberé utilizar otra variable, o definir alguna otra estructura de datos más compleja que permita almacenar más de un valor.
